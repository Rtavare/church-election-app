Church Election App — How to Run the Vote

For the pastor / committee president & secretary · App: rtavare.github.io/church-election-app · EN/ES toggle top-right

1Start the session (host device)

  1. Enter the session title and church name.
  2. Tap to select every department for next year — they run in the order you tap them. Add custom departments with the text box.
  3. Set the Voting PIN and the Host PIN (see box below — they must be different).
  4. Tap Start session. The screen shows the first department, the QR code, and the Voting PIN.

🔑 The two PINs + Session ID — keep them straight

Voting PIN
(6 digits)		For the committee. Shown on the big screen with the QR. Used only to join, submit names, and vote.
Host PIN
(6 digits)		Pastor/president only — never share with the committee. Together with the Session ID it restores the session and opens the dashboard.
Session IDThe session's permanent ID (host screen, dashboard panel). Tap “Copy Session ID + Host PIN” there and save it somewhere safe before you begin.

2Names — repeat per department

  1. Committee members scan the QR (or enter the Voting PIN) and submit names from their phones.
  2. Submitted names appear in a yellow box on the host screen. The pastor or secretary taps + Add to put a name on the official list (or types it directly).
  3. Each added name gets the next number — 1, 2, 3… Duplicate names are rejected automatically.
  4. Optional: turn OFF the “Let the committee submit names” switch — then only the president/secretary can add names.
  5. With 2+ names, tap Start voting.

3Vote · 4Approve

  1. Phones show the numbered list and big number tiles. Each member taps the number that matches the name. One vote per phone, per department. Ballots are anonymous — no names are recorded.
  2. Watch the live vote count on the host screen. When everyone has voted, tap Close & show results.
  3. Review the ranked results, then tap Submit as approved → add to dashboard. This locks the result: #1 = Director #2 = Sub-Director.
  4. Tap Next department and repeat steps 2–4.

5The live dashboard & finishing

  • Dashboard: open rtavare.github.io/church-election-app/#/dashboard and enter the Session ID + Host PIN. Church at the center, departments branching out, each with its approved Director and Sub-Director — updating live as you approve. Unapproved departments show live status (collecting names, voting, waiting).
  • Finish: after the last department is approved, the app shows the elected board summary. Tap Copy summary for the minutes — it includes the Session ID and date for the church records.

⚠ If something goes wrong

  • Host device dies / browser closes: on any device, open the app's start screen → Restore a session → enter Session ID + Host PIN. You pick up as host exactly where you left off.
  • Voting PIN leaked: in the QR panel, Change PIN. The old QR/PIN stops working immediately; votes already cast stay counted. Announce the new PIN to the committee.
  • Host PIN compromised: change it in the dashboard panel on the host screen.
  • A phone says “Session not found”: it's using an old QR/PIN — have them scan the current QR on the host screen.
  • Golden rules: the two PINs are never the same · the Host PIN never goes to the committee · no official appears on the dashboard until their department's vote is submitted as approved.
